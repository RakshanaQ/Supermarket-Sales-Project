# Supermarket Sales Data Analysis & Power BI Portfolio Project

An end-to-end data analysis project demonstrating data cleaning, SQL querying, and interactive dashboard creation using 1,000+ supermarket transactions.

## 📂 Project Structure & Workflow
* **`data/raw/`** - Contains the original, uncleaned raw dataset.
* **`data/processed/`** - Contains the cleaned dataset (`Cleaned_Supermarket_Sales.csv`) used for production.
* **`SQL/`** - Contains verified SQL analysis queries (`queries.sql`).
* **`Dashboard/`** - Contains the Power BI `.pbix` file and a visual preview.

## 🛠️ Tech Stack & Skills Demonstrated
* **Data Cleaning & Transformation:** Handled messy formatting (such as embedded symbols) to prepare raw data for analysis.
* **SQL Querying:** Extracted revenue insights grouped by customer demographics, product lines, and branches.
* **Power BI:** Built a 7-chart interactive dashboard tracking branch performance, customer types, payment methods, gender spend, city gross income, and ratings.
